# Farmora — SIH Prototype

This is a browser-based prototype focused on the innovation feedback:

- Localized price intelligence
- Crop-specific price trends
- Sale-window recommendations
- Verified buyer matching
- Net realisation comparison
- Offer + counter-offer workflow
- End-to-end transaction tracking
- Buyer verification and grievance demo

## Run in VS Code

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install the **Live Server** extension by Ritwick Dey.
4. Open `index.html`.
5. Right-click → **Open with Live Server**.

No npm install is required for this HTML/CSS/JavaScript prototype.

## Demo data
All market prices, buyer records and recommendations are illustrative prototype data. They are not live mandi prices.
